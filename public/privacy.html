Політика конфіденційності

Останнє оновлення: листопад 2026 року

1. Загальні положення

Застосунок та вебсервіс «КешбекРадар» (ua.cashbackradar.app) є персональним довідником і калькулятором вигідності кешбеку банківських карток України.

Сервіс не є банком, не надає платіжних або кредитних послуг, не підключається до банківських рахунків і ніколи не запитує номери карток, CVV-коди, PIN-коди чи паролі від онлайн-банкінгу.

2. Які дані обробляються

  • Локальний режим (за замовчуванням у мобільному застосунку): назва обраного банку, назва картки та налаштовані вами відсотки кешбеку зберігаються виключно локально на вашому пристрої (localStorage) і не передаються розробнику чи третім особам.
  • Хмарний режим (у разі ввімкнення синхронізації облікового запису): електронна пошта, ім’я учасника та ваші налаштовані правила кешбеку зберігаються в захищеній базі даних Supabase із шифруванням під час передавання (HTTPS/TLS) та ізоляцією доступу на рівні Row Level Security (auth.uid()).

3. Передача даних третім особам та реклама

Ми не продаємо, не здаємо в оренду та не передаємо персональні дані користувачів третім особам. У застосунку відсутня реклама та сторонні рекламні трекери (Advertising ID не використовується).

4. Видалення акаунта та даних

Ви можете в будь-який момент видалити всі локальні дані через налаштування пристрою («Очистити дані» застосунку) або видаливши картки в гаманці. Для видалення хмарного акаунта та всіх пов’язаних із ним записів зверніться на електронну пошту: support@cashbackradar.ua.

Privacy Policy (English Summary)

Last updated: November 2026

Overview & Data Handling

CashbackRadar UA (ua.cashbackradar.app) is a personal cashback calculator and merchant MCC reference guide. It does not process payments, issue loans, or collect bank card numbers, CVVs, PINs, or Open Banking credentials.

In the default offline/local mode, all card labels and cashback percentages are stored strictly on the user's device and are never transmitted to any server. If optional cloud sync is enabled, only the user's email, display name, and custom cashback rules are stored securely over HTTPS with strict Row Level Security isolation. No ads or third-party ad trackers are used.

For data deletion requests or privacy inquiries, contact: support@cashbackradar.ua.
